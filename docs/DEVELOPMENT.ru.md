# Лаки 🐰 — заметки для разработки (RU)

PWA (веб-приложение) без сборки и зависимостей. Дизайн и механики описаны в [DESIGN.ru.md](DESIGN.ru.md). Публичное описание — в [README.md](../README.md).

## Запуск на компьютере

```bash
cd ~/Documents/Tamagochi
python3 -m http.server 8123
```
Открыть http://localhost:8123. С параметром `?debug` в консоли браузера доступен объект `window.game`.

## Быстро посмотреть на iPhone (та же Wi-Fi сеть)

1. На Mac запустить сервер командой выше.
2. На iPhone в Safari открыть `http://<IP Mac>:8123`. IP можно узнать командой `ipconfig getifaddr en0`.

Так игру удобно проверить, но без интернета она работать не будет (iOS разрешает офлайн-режим только по https).

## Установка «насовсем» (работает офлайн)

Нужен любой бесплатный статический хостинг с https: GitHub Pages, Netlify или Cloudflare Pages. На сервере лежат только файлы игры. **Весь прогресс хранится на телефоне** (localStorage), аккаунтов и сбора данных нет.

1. Выложить папку на хостинг.
2. На iPhone открыть ссылку в Safari → «Поделиться» → **«На экран Домой»**.
3. Открыть игру с иконки. После первого открытия она работает без интернета.

Прогресс привязан к иконке на экране «Домой». Если удалить иконку, прогресс пропадёт.

### Обновление версии
При публикации через GitHub Actions версия кеша в `sw.js` подставляется автоматически (хеш коммита). Локально ничего менять не нужно.

## Ограничения «Экранного времени» (Screen Time)

Настраивается на телефоне ребёнка или через Семейный доступ с телефона родителя.

- **Разрешить только игру:** Настройки → Экранное время → Контент и конфиденциальность → Контент в App Store, Медиа, Веб и Игры → Веб-контент → **«Только разрешённые сайты»**, добавить адрес игры. Safari и веб-приложение откроют только его.
- **Ограничить время:** Экранное время → Лимиты приложений → Добавить лимит → **Веб-сайты** → домен игры.
- **Safari не блокировать полностью** (Разрешённые приложения → Safari = выкл): веб-приложения с экрана «Домой» работают на движке Safari и тоже перестанут открываться.

В самой игре тоже есть ограничения. Их можно настроить в родительском разделе (⚙️ → пароль родителя; задаётся на телефоне при первом входе, есть код восстановления и сброс через 24 часа): длина сессии, отдых после неё, максимум игры в день, отбой и подъём. Там же есть **Турбо** для проверки и показа (без лимитов; прогресс до турбо возвращается при выключении) и **Начать заново**.

## Голоса персонажей

Реплики озвучены заранее голосами Google Chirp 3 HD: Лаки — Fenrir, Тали — Orus, лягушка — Charon. Записи лежат в `audio/`, всего ~1250 MP3, ~15 МБ. Если записи для фразы нет (новая фраза или другое имя в родительском разделе), звучит встроенный голос iOS.

- **После правки текстов** в `js/i18n.js`, `js/dialogs.js` выполнить `node tools/gen-voices.mjs`. Скрипт озвучит только новые и изменённые фразы и удалит лишние записи. Ключ Google берётся из `.env.local` (`GOOGLE_TTS_KEY=...`). Этот файл никому не передавать и не выкладывать.
- **Если Google ответил 429** (превышен лимит в минуту), подождать минуту и запустить скрипт ещё раз.
- **Сменить голос или высоту:** `js/voicekey.js` → `VOICES`. `rate` — ускорение при проигрывании, чем больше, тем выше голос. Если меняешь `voice`, удали папку `audio/` и запусти генерацию заново.
- **Сравнить голоса:** `node tools/voice-trial.mjs`, затем открыть `/voice-trial/`.
